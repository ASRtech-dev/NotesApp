Storage hierarchy and JSON ingestion guide

📥 01-inbox/

Stores raw thoughts captured with zero friction as plain Markdown files (inbox-*.md). Protects working memory by postponing categorization until a dedicated processing block.

Zero friction • Sweller 1988
📚 02-source-notes/

Files named fuente-*.md with author metadata, media type (book, paper, video), exact quotes, and paraphrased key takeaways. Separates external information from personal synthesis.

Bibliographic grounding
⚛️ 03-atomic-notes/

Files named atomica-*.md. Each note houses exactly ONE autonomous idea written in your own words (Generation Effect), stating why it matters and linking to related concepts.

Zettelkasten • Slamecka 1978
🗺️ 04-content-maps/

Files named mapa-*.md. High-level conceptual organizers (Kiewra 1991). Strictly requires a relational reason explaining why each note belongs to that thematic map.

Required connection reason • Kiewra 1991
🎯 05-self-assessment/

Files named pregunta-*.md. Question and answer pairs generated from each atomic note. Provides fuel for the SM-2 active recall testing algorithm.

Active Recall • Dunlosky 2013
⚡ 06-spaced-repetition/

The reviews.json file. Logs review timestamps, Ease Factors, repetition counts, and interval days to mathematically schedule your next optimal review sessions.

SM-2 algorithm + Interleaving

Welcome to NotesApp

💡 💡 Zero Friction & Working Memory (Sweller 1988)

Human working memory has strict bandwidth limits. Interrupting reading or thinking to classify an idea derails deep attention. Capture thoughts here instantly and process them in a dedicated batch.

Inbox

Capture raw thoughts with zero friction. Process them into atomic notes or sources later.

⚛️ ⚛️ Atomicity Principle & Generation Effect (Luhmann & Slamecka 1978)

Each atomic note must be self-contained and discuss exactly one concept. Explaining it entirely in your own words (Generation Effect) forces conceptual reconstruction, dramatically boosting retention over passive copying.

Atomic Notes

One single idea per note, formulated in your own words and deliberately connected.

📚 📚 Bibliographic Grounding & Critical Synthesis

Source notes safeguard authorship and exact citations. They allow you to trace the origin of an idea and spark new atomic concepts without contaminating the conceptual purity of your permanent network.

Source Notes

Bibliographic registry, verbatim quotes, and key paraphrased takeaways from consulted works.

🗺️ 🗺️ Matrix Organization vs Passive Outlines (Kiewra 1991)

Linear outlines foster illusions of competence. In NotesApp, every note added to a map strictly requires a 'reason' explaining its relationship, training high-order relational processing.

Content Maps

Hierarchical structures with mandatory relational reasoning (Kiewra et al. 1991).

⚡ ⚡ Active Retrieval Practice with Interleaving (Dunlosky 2013 & SM-2)

Retrieving information from memory fortifies synaptic pathways far more than passive review. The SM-2 algorithm schedules reviews right at the threshold of forgetting, while cross-topic interleaving sharpens conceptual discrimination.

Spaced Repetition Session

Optimized SM-2 algorithm with round-robin topic interleaving for maximum consolidation.

    🧠 🧠 Cognitive Architecture of the NotesApp Prompt

    Language models typically summarize passively or copy verbatim. This master prompt forces the AI to behave as a cognitive architect: enforces strict single-idea atomicity, blocks copy-pasting to ensure generative wording, creates SM-2 flashcards, and requires relational reasons in every content map.

    🤖 LLM Assistant & Master Prompt

    Transform any document, book, course, or transcript into a structured package compatible with NotesApp.

    Prompt Language:

    The 4 Unbreakable Scientific Rules of the Prompt

    ⚛️

    1. Strict Atomicity (Luhmann)

    Exactly one autonomous idea per note. If the source material touches multiple concepts, the AI splits them into independent files.

    🛡️

    2. Generation Effect (Slamecka)

    Copying verbatim paragraphs is prohibited. The LLM must clearly explain the underlying mechanism in its own words.

    🎯

    3. Active Recall SM-2 (Dunlosky)

    Every atomic note must have an open retrieval question and key answer to fuel spaced retrieval practice.

    🗺️

    4. Content Maps with Mandatory Reason (Kiewra)

    No note is linked to a map without an explicit 'razon' field explaining why and how it enriches that conceptual organizer.

    Supporting research

    HIGH UTILITY

    Self-testing (practice testing)

    Dunlosky et al. (2013); Roediger & Karpicke (2006)

    Trying to recall an answer from memory can improve retention compared with passive rereading. Each atomic note therefore has an associated question.

    HIGH UTILITY

    Distributed practice (spaced repetition)

    Ebbinghaus (1885); Cepeda et al. (2006)

    The brain consolidates memories during rest and sleep. Spacing reviews with SM-2 helps counter forgetting and supports longer retention.

    CONCEPT DISCRIMINATION

    Interleaving

    Kornell & Bjork (2008); Rohrer & Taylor (2007)

    Reviewing topics in blocks can create misleading familiarity. Alternating questions across topics requires you to identify which concept to apply.

    DEEP ENCODING

    Generation effect

    Slamecka & Graf (1978); Mueller & Oppenheimer (2014)

    Writing in your own words requires reconstructing meaning. NotesApp blocks pasting in idea fields and warns about phrase overlap with the source.

    MATRIX ORGANIZATION

    Matrices and linear outlines

    Kiewra et al. (1991, 1999)

    Explaining the reason for a connection encourages relational processing and helps prevent disconnected collections of notes.

    LOW UTILITY (DISCOURAGED)

    Passive rereading and highlighting

    Dunlosky et al. (2013)

    These popular techniques can create a sense of familiarity without lasting recall. NotesApp does not include a passive highlighting mode.
